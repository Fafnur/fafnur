### 🛠 What I bring to a team

- **Legacy migration without stopping the business.** Moving old code to Angular, Nx, NgRx, SSR and i18n while new
  features keep shipping.
- **Architecture that scales.** Nx monorepos with clear library boundaries, shared UI kits, generators and conventions
  that new developers pick up in days, not months.
- **Fast, accessible, SEO-ready apps.** SSR and static prerendering, Lighthouse-driven performance work, a11y checked
  automatically in e2e.
- **Team leadership.** Setting tasks, code review, mentoring — I've been training frontend developers since 2015.
- **More than the frontend.** APIs on NestJS and Node.js, mobile apps on Flutter (BLoC, get_it), even games on Unity3D
  and Unreal Engine back in the day.
- **AI-driven workflow.** I bring AI into the team's daily process, not just into my own editor — see below.

### 🤖 AI in the development process

- **Workflow with Claude Code and Codex.** Project rules, skills and conventions, so agents generate code the way the
  team writes it and every change still passes lint, tests and review.
- **MCP servers.** Connecting agents to the tools the team already uses — trackers, knowledge bases, Git hosting,
  error monitoring and databases.
- **Task automation.** Agents create and update tasks from discussions, code and incidents, so the board stays in sync
  with the actual work.
- **AI reviewers.** Review agents that check merge requests against the team's conventions before a human looks at
  them.
- **Local LLMs.** Running open models like Qwen in LM Studio — for experiments and for code that must not leave the
  company.

### 🌐 This repository

The source of [fafn.ru](https://fafn.ru) — and a showcase of how I like to build things:

- **Angular 22** with static prerendering, **Nx 23** monorepo, **Tailwind CSS 4**, Angular i18n
- **Vitest** unit tests and **Playwright + axe** e2e for every page
- Every merge into `main` is a release: GitHub Actions lints, tests, builds, deploys and tags it automatically
- Custom **Claude Code skills** for components, tests, i18n, e2e and dependency updates

```bash
yarn start   # dev server
yarn check   # lint, test, build, e2e — a task is done when it is green
```
